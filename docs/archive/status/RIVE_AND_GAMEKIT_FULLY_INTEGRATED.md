```

    ↓

Gamification Provider / Integration Helper
    ↓

    ↓
RiveGameGuideController (Update State)
    ↓

    ↓
GameKit Engine (If Game)
    ↓
Polie Backend (Evaluate)
    ↓
Backend (Save State)
```
