Layer 02 — Game Suite

Seven Realms.
One Universe.

01
Flagship RPG · Narrative
Village of Voices
You arrive in a procedurally generated African region with no language. Survival requires mastering the social hierarchy through correct speech, tonal accuracy, and cultural protocol. Every NPC has a memory. Every mistake has consequences. Every proverb is a key.
Dialogue Combat Engine — Grammar score, tone precision, cultural fit, and emotional resonance all calculate your persuasion strength in real-time
NPC Memory Persistence — NPCs remember every interaction, mistake, gift, and insult across sessions via MongoDB NPCMemory collection
Procedural Regional Dialects — Each region generates dialect variants. Yoruba speaker in Lagos vs Ibadan get slightly different vocabulary challenges
Proverb Unlock System — 500+ authentic proverbs per language, each tied to quest branches. "Àgbọ̀n tí a bá gbẹ́ ni a ń gbẹ́" — correctly deploy it to unlock the Elder's alliance
Social Hierarchy Engine — Age, gender, and role-specific language registers enforced. Wrong register = social penalty. Correct = respect XP
Seasonal World Events — Real African festivals (Sallah, Timkat, Eid, Egungun) trigger limited-time in-game events with cultural context
02
Competitive · PvP
Verbs & Valor
Real-time 1v1 language duels with ELO ranking. Three modes: Blitz conjugation, Sentence Strategy, and live Tone Duel. Spectator mode. Replay analysis. Seasonal ladders. The linguistic Olympics.
Cross-Language Duels — Swahili vs Yoruba speaker competing on shared vocabulary roots
Anti-Cheat Server Validation — All submissions validated server-side via NestJS with Redis rate limiting
Live Pronunciation Duel — AI scores both players' tone accuracy simultaneously, millisecond latency via WebSocket
03
Strategy · City Builder
Àdúgbò Builder
Construct a thriving African village where every building requires language mastery to unlock. Festivals demand correct chanting. Trade requires negotiation dialogues. Population happiness tied to linguistic accuracy.
Language Economy — Vocabulary mastery generates in-game currency. Grammar streak multipliers. Proverb knowledge unlocks rare buildings
Festival System — 12 authentic festivals per language per year, each requiring specific chants and ceremonies
04
Arcade · Rhythm
Tone Runner
Guitar Hero meets tonal phonology. Words fall. You tap the tonal contour or speak it. Music adapts to your accuracy. This solves the single biggest failure in all African language apps: tone neglect.
Live Speech Input — Microphone mode scores tone in real-time using the Python AI microservice
Adaptive Music Engine — Afrobeats, Highlife, Amapiano tracks that evolve based on accuracy score
05
Story · Mythology
Griot's Grimoire
A narrative adventure through African mythology. Each pantheon requires its own language. Orisha speak Yoruba. Anansi speaks Twi. The Ancestors speak Ge'ez. Language becomes mythology becomes immersion.
Mythology Engine — 50+ mythological entities across Yoruba, Akan, Zulu, Ethiopian, Egyptian, Berber cosmologies
Oral Tradition Mode — Listen to stories narrated by native speakers, then retell them. Comprehension scoring via NLP
06
Social · Clan System
Ubuntu Clans
Form clans of learners. Clan language = collective chosen language. Clan tournaments. Mentor/apprentice bonds. The social graph becomes the retention engine. Ubuntu: I am because we are.
Diaspora Reconnection Mode — Match diaspora learners with heritage speakers in Africa for mentorship duels
Clan Leaderboard — Redis-powered real-time clan ranking by language progress score
07
UNESCO Mode · Preservation
The Living Archive
The seventh game is not entertainment — it is civilization. Community-driven content creation where native speakers record vocabulary, proverbs, and stories. Players learn endangered languages and the recordings are preserved permanently. Every session contributes to a growing digital linguistic archive.
Community Recording Studio — Native speakers record in-app. AI cleans audio. Community votes on accuracy. Best recordings enter the canon
Endangered Language Alerts — When a language has fewer than 1,000 active speakers, the game generates preservation quests and alerts players
Digital Griot Program — Master learners earn the Griot title and their recordings are attributed permanently in the archive
Government API Bridge — Export recorded data directly to UNESCO's endangered language databases and national archives

Layer 04 — AI & Intelligence

The Machine That
Speaks Africa.

Pronunciation AI
Python FastAPI microservice. MFCC feature extraction via Librosa. Parselmouth for pitch contour. Wav2Vec2 fine-tuned on African language corpora from Masakhane, Mozilla Common Voice Africa, and 500+ hours of native recordings.
  • Phoneme-level deviation scoring per language
  • Click consonant detection (Zulu, Xhosa)
  • Tone contour classification (H/L/M/F/R per syllable)
  • Vowel harmony validation (Yoruba, Igbo, Ewe)
  • Nasalization detection
  • Response payload < 200ms on GPU
  • Fallback to rule-based scoring offline
Dialogue Intelligence
NestJS service powered by AfroXLMR and Masakhane NLP models. Scores grammatical correctness, cultural appropriateness, emotional register, and contextual relevance of player responses.
  • Grammar parse tree validation per language
  • Noun class agreement checking (Bantu languages)
  • Tonal orthography validation
  • Cultural register appropriateness scoring
  • Proverb semantic similarity matching
  • Oral retelling NLP scoring
  • Dynamic difficulty calibration per user
Pedagogical Engine
Spaced repetition algorithm (SM-2 extended) with cultural weighting. Tracks 40+ error categories. Predicts dropout 72 hours before it happens. Generates adaptive quests targeting weak spots.
  • CEFR-adapted levels for African languages (A0–C2)
  • Weak phoneme clustering and targeted practice
  • Error pattern recognition across sessions
  • Drop-off prediction model (73% accuracy)
  • Adaptive quest difficulty generation
  • Comprehensible input pacing per learner
Dialect & Variation AI
A novel system that handles the enormous dialectal variation within African languages. Yoruba spoken in Lagos differs from Ibadan. Zulu in KZN differs from Gauteng. The AI maps regional variants and teaches learners appropriately.
  • Dialect classification on audio input
  • Regional vocabulary variant tagging
  • Code-switching detection and scoring
  • Historical vs modern usage differentiation
  • Sacred/ceremonial register separation
  • Pidgin and creole awareness (Naija, Sheng)

Layer 05 — Cultural Systems

Not Edutainment.
Cultural Immersion.

🥁
Talking Drum Engine
Recreate Yoruba and Akan talking drum language patterns. Map tonal speech to drum rhythms. Unique gameplay mechanic that teaches tone through percussion before spoken practice.
🦚
Kente Grammar System
Akan grammar visualized as kente weaving. Sentence structures become pattern colors. Complex grammar concepts taught through textile metaphors rooted in the culture's own design language.
🌿
Proverb Oracle
500+ authentic proverbs per language with cultural context, etymology, and usage situations. Correctly placing a proverb in dialogue unlocks hidden quest branches and elder alliances.
🏺
Oral Tradition Recorder
Players listen to native-speaker stories, then must retell them. NLP scores the retelling on accuracy, tone, and narrative structure. Teaches oral tradition as a living practice, not a relic.
🌙
Social Register System
Many African languages have strict registers: elder speech, peer speech, market speech, sacred speech. The game enforces these registers with consequences — wrong register to an elder is a social failure.
⚡
Orisha / Spirits Mode
Yoruba Orisha, Akan spirits, Zulu ancestors — each deity speaks with distinct vocabulary, tone patterns, and idioms. Learners must adapt their speech to mythological entities with unique linguistic personalities.
🎭
Festival Calendar
Real-world African festivals trigger in-game events. Egungun masquerade, Homowo harvest, Timkat Ethiopian Epiphany, Sallah — all with authentic vocabulary, songs, and ceremonial phrases required to participate.
🔱
Adinkra Symbol Quest
Akan Adinkra symbols embedded as hidden puzzles. Each symbol represents a philosophical concept. Players who learn the concept in Twi unlock the symbol as a permanent clan badge.
🌍
Migration Story Mode
Track the historical migration of Bantu languages. Play through language evolution across centuries. Watch vocabulary shift as characters move across the continent — real historical linguistics as gameplay.
