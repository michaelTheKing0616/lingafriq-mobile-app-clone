# Language kits (week 0–1)

Per-language kits are generated with `tools/content_pipeline/language_kit.py` (card **P4-120**). Each kit holds orthography, dialect standard, phonology, seed lexicon (licence-checked against `tools/content_engine/licences/register.csv`), and a paid native reviewer panel before AI bootstrap (P4-121).

Shipped kit JSON files are not committed until a language squad finishes week 0–1; use the generator and schema at `schemas/v2/language_kit.schema.json`.
