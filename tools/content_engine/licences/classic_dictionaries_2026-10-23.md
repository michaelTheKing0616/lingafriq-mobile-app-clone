# Classic dictionaries — copyright verification (2026-10-23)

This note covers two curriculum reference works whose copyright status is **unconfirmed**:

- **abraham-yoruba-1958** — Abraham, *Dictionary of Modern Yoruba*, 1958 (archive.org)
- **bargery-hausa-1934** — Bargery, *Hausa–English*, 1934 (online)

Curriculum §2.3 (L265–L272) lists these works for reference and verification only. It states that author-death terms are **likely still running in the UK**. Counsel has **not** confirmed either work.

Both sources remain **excluded** in the licence register until public domain status is confirmed by counsel.
