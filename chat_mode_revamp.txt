# Product vision (single sentence)

Build a *socially safe, ultra-discoverable, language-first messaging suite* with Material 3 aesthetics that blends **private encrypted chats**, **scoped global chat walls**, and **language-matching social discovery**, optimized for African languages and culture — combining the familiarity of WhatsApp, the discovery & exchange of Tandem/HelloTalk, and the content moderation and community tooling of modern social platforms.

---

# Top-level principles (design & policy)

1. **Learner-first**: make every chat action an opportunity to learn (inline corrections, phrasebook pin, SRS export, practice drills).
2. **Privacy & consent**: default to private; global features are opt-in; contacts are added via explicit invites or contact discovery toggles. End-to-end encryption is default for private chat.
3. **Trust & safety**: layered moderation (automated filters, community reporting, human review).
4. **Cultural authenticity**: language-specific orthography enforcement, local content packs, and regional discovery filters.
5. **Beautiful, consistent UI**: use Material 3 tokens, dynamic theming, motion, and accessible color contrasts.

# Feature spec — by mode

### 1) Global Chat Mode — “Polie World Wall” (scoped, safe, discoverable)

**Purpose:** a moderated, public feed for language learners to practice in real time and meet speakers worldwide. Scoped filters allow only relevant content per user.

**Core features**

* **Scoped Streams**: Global wall where each user chooses filters: Country (e.g., Nigeria), Target language (Yorùbá), Learning level (A1–C2), Topic (travel, market, jokes). Only posts matching filters appear. Support multi-filter combos (e.g., Nigeria + Yoruba + A1).
* **Rooms & Channels**: Persistent channels for languages, countries, cities, and topics. Channels can be public, community-invite, or private.
* **Geo & Language Filtering**: optional proximity layer — show posts from nearby users (city or country) and allow language preference filtering. (Based on user settings.)
* **AI-Assisted Post Types**:

  * Text posts (with optional auto-correct/diacritics preview and toggle)
  * Audio posts (voice notes with auto-transcription & tone visualization for tonal languages)
  * Image posts (with OCR-based object labeling to generate vocabulary)
  * Short story / roleplay prompts that seed a multi-turn chain for practice
* **Real-time features**: upvotes, emoji reactions, threaded replies, typing indicators, presence (online/away).
* **In-line Learning Tools**:

  * “Teach me” button to convert a post into a micro-lesson (LLM generates practice tasks, translations, IPA, minimal pair drills).
  * “Save to phrasebook” — add a sentence to SRS deck with one tap.
  * “Quick translate” — immediate translation + diacritics correction.
* **Quality & moderation**:

  * Automated moderation pipeline (profanity/abuse detection in relevant languages), AutoMod-like confidence scoring, and community flagging.
  * Verified native-speaker tags (optional paid or community verified badges).

**Cool extra ideas**

* **Pinned Daily Challenges**: daily language micro-challenges (e.g., “Use this sentence in a reply — best replies get badges”).
* **Live micro-classrooms**: scheduled “practice hours” run by volunteer native-speakers (with capacity, RSVP).
* **Proximity audio rooms**: ephemeral voice rooms where speakers nearby can practice — spatial audio optional for immersion. ([SpatialChat Center][5])

---

### 2) Private Chat Mode — WhatsApp-like with upgraded learning features

**Purpose:** one-to-one secure conversations that behave like WhatsApp but are language-learning aware.

**Core features**

* **Contact discovery & add flows**

  * Search by username, email, phone (optional), or contact link.
  * **Connection Links**: generate deep invite links (expiring, single-use or multi-use) which can be shared on social apps/WhatsApp/Twitter — clicking opens a limited “Add Polie contact” invite flow.
  * **QR codes** to add contacts quickly (in-app scanner).
  * **Contact Suggestions**: friend suggestions based on overlapping target languages, mutual contacts, similar levels, and location.
  * **Social proof**: short learner profile with top languages, native languages, badges (verified, tutor, high-rated).
* **Chat features**

  * Typing indicators, read receipts, presence (online/offline).
  * Audio messages (with play speed control), voice transcription, and tone visualization for tonal languages.
  * Video and screen-share for in-call tutoring.
  * Message reactions, replies, and threaded mini-conversations.
  * **Message types as learning primitives**: send “phrase cards” (with canonical text + audio), “roleplay turn” (pre-filled prompt + response slot), “mini-quiz” (1–3 questions).
* **Privacy & security**

  * E2EE for 1:1 chats. Allow pinned device keys and optional cloud backup with user encryption passphrase.
  * Contact discovery opt-out toggle for users who prefer anonymity.
* **Smart invite UX**

  * On generating a connection link the user can decide: add as friend directly, ask to chat first, or schedule a 10-minute practice call.
  * Allow “import from Telegram” or “send via email” with one-click copy/paste of invite card.
* **Pro-level additions**

  * “Study buddies” pairing: allow opt-in scheduled practice sessions with reminders, automatic SRS sync on completed sessions.

**Cool extra ideas**

* **Contact trust score**: earned via mutual endorsements/ratings from language exchanges (helps surface better partners).
* **Cross-platform deep invites**: pre-filled social share cards that show the new contact’s top languages & practice availability (love the “Add me to Polie” card).

---

### 3) Connect With Users Mode — language-specific communities & matchmaker

**Purpose:** match learners and native speakers for exchange and community help.

**Core features**

* **Language matching feed**:

  * Show people learning the same language and at similar levels.
  * Filter by timezone, availability (scheduled hours), voice proficiency, and dialect.
* **Community Hubs**:

  * Each language has a hub with pinned grammar tips, proverb of the day, mini-lessons, and Top Learners leaderboard.
  * Volunteer native-speaker programs where experienced users host Q&A hours.
* **Structured pairing flows**:

  * Instant Tandem: match now for a 10–15 minute practice session.
  * Scheduled Tandem: propose timeslots; integrated calendar invites; auto reminders & session notes exported to SRS.
* **Micro-mentorship**:

  * Mentor badges; paid or volunteer mentorship; mentor profiles (rate, specialties, verified).
* **Quality & reputation**

  * Ratings after exchanges (optional, with anonymity).
  * Verified native-speaker badges via document/audio verification or community vouching.

**Cool extra ideas**

* **Micro-tasks exchange**: earn points by helping others (correcting sentences, reviewing audios), redeem points for paid features (pro voices, mentor discounts).
* **Crowd-correct mode**: post your audio; community members can annotate phoneme-level feedback (ideal for tonal languages).

# Backend & infra details

**Real-time stack**

* Websockets (FastAPI/Starlette or socket.io) or serverless real-time (Pusher / Supabase Realtime) for presence, typing indicator, and live channel updates.
* Pub/Sub (Redis Streams / Kafka) for fan-out to channels.
* Media storage: S3-compatible with signed URLs.
* ASR & TTS services: pre-integrated (wav2vec2 ASR on serverless, Coqui/ElevenLabs TTS for native voices).
* Forced-aligner pipelines for pronunciation feedback (MFA/wav2vec2).
* DB: Postgres (core) + Redis (presence, ephemeral state) + vector DB (semantic search for retrieval & RAG).

**APIs (examples)**

* `POST /api/chats` create private chat
* `POST /api/chats/:id/messages` send message (supports attachments)
* `GET /api/chats/:id/stream` websocket for real-time
* `GET /api/world/posts` with filters `{country, language, level, topic}`
* `POST /api/invite/link` create connection link with TTL and usage limit
* `POST /api/pronunciation/score` upload audio -> forced-aligner -> returns phoneme errors

**Scalability**

* Use horizontal scaling: RabbitMQ/Kafka + stateless api nodes + autoscaled ASR workers.
* For global walls, apply pagination & server-side topic filtering; consider per-channel sharding.

# Moderation & safety (must-haves)

* **Automatic filters**: profanity filters for target languages, hate speech detectors, spam classifiers, and image moderation.
* **AutoMod pipeline**: messages flagged by model -> held for review; multiple thresholds: immediate removal, temporary hold, or community review.
* **Reporting flow**: report → triage → escalate to human moderators (native reviewers) for language-specific contexts.
* **Rate limits & trust gating**: new users limited posting & media uploads until verified.
* **Transparency**: keep an appeal flow & show moderation reasons.
