Omenala

More than just 'culture', Omenala represents the divine alignment of action with the earth—a living philosophy of the Igbo people.

Etymological Decomposition

Ome To do, to act, to manifest.
na In, at, or with.
ala The earth, the ground, the goddess Ani.

"That which happens on the land."
