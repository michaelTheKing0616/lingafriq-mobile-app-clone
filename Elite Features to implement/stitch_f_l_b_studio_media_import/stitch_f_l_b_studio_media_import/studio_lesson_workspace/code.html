Cultural Context

The Gangan is more than an instrument; it is a linguistic bridge. Because Yoruba is a tonal language, the drummer can manipulate the tension cords to shift pitch, effectively "speaking" proverbs, warnings, and histories over great distances.

Drummers in this tradition belong to specific lineages, often carrying the name Ayan to signify their ancestral connection to the deity of drumming.

"The drum does not speak for itself; it speaks for the soul of the people."
