Griot's Note

In East African coastal architecture, the Nyumba (house) is more than shelter—it's a reflection of the landscape. Using coral stone and thatch, these dwellings harmonize with the Mlima (mountain) terrains, designed to catch the monsoon breezes.

Did you know?

The word "Mlima" refers to a mountain, while "Kilima" refers to a hill. The prefix shift (M- to Ki-) subtly changes the scale of the landscape in the Swahili imagination.
